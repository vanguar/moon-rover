# Луноход: борозда Хэдли

Браузерная 3D-игра (PWA): езда на шестиколёсном луноходе от первого лица по **реальному рельефу**
места посадки «Аполлона-15» — борозда Хэдли, участок 4 × 4 км (26.13° с.ш., 3.61° в.д.).
Работает на ПК и телефоне, устанавливается как приложение и играет офлайн.

**Играть:** https://vanguar.github.io/moon-rover/

Стек: Vite + TypeScript + Three.js, физика — Rapier (`@dimforge/rapier3d-compat`).

## Запуск

```bash
npm install
npm run dev       # http://localhost:5173/moon-rover/
npm run build     # сборка в dist/
npm run preview   # предпросмотр сборки
```

Нужен Node.js 20+. Игровые данные (`public/data/`) уже в репозитории; пересобирать их не обязательно.

### Пересборка данных рельефа

1. Скачайте в `raw_data/` (папка в `.gitignore`):
   - DTM: [NAC_DTM_APOLLO15.TIF](https://pds.lroc.im-ldi.com/data/LRO-L-LROC-5-RDR-V1.0/LROLRC_2001/DATA/SDP/NAC_DTM/APOLLO15/NAC_DTM_APOLLO15.TIF) (140 МБ, 2 м/пикс., float32)
   - ортоснимок: [NAC_DTM_APOLLO15_M111571816_50CM.TIF](https://pds.lroc.im-ldi.com/data/LRO-L-LROC-5-RDR-V1.0/LROLRC_2001/EXTRAS/BROWSE/NAC_DTM/APOLLO15/NAC_DTM_APOLLO15_M111571816_50CM.TIF) (560 МБ, 0.5 м/пикс.)
2. `pip install rasterio numpy pillow`
3. `npm run data` (= `python tools/prepare_terrain.py`)

Скрипт вырезает окно 2000 × 2000 пикс. (4 км), заполняет пропуски, сохраняет 16-битный PNG-heightmap,
ортоснимок 4096² JPG, маску теней от рельефа для игрового Солнца и `terrain.json`
(размеры в метрах, мин/макс высота, координаты места посадки, направление Солнца). Всего ≈ 7 МБ.

## Управление

| Действие | Клавиатура | Геймпад | Телефон |
|---|---|---|---|
| Газ | W / ↑ | RT | педаль «ГАЗ» или джойстик вверх |
| Тормоз / назад | S / ↓ | LT | педаль «ТОРМ» или джойстик вниз |
| Руль | A / D, ← / → | левый стик | джойстик или наклон телефона |
| Ручной тормоз | Space | A | «РУЧН.» |
| Камера: кабина / снаружи | C | Y | 👁 |
| Поставить на колёса | R | B / Back | ⟲ |
| Фары | H | X | 💡 |
| Меню / пауза | Esc | Start | ☰ |
| Осмотреться | мышь (перетаскивание), колесо — дистанция | — | провести по экрану |

Руление наклоном включается в меню (на iOS браузер запросит разрешение на датчик ориентации).
Нейтраль калибруется при нажатии «Поехали».

## Физика и графика

- **Рельеф:** LROC NAC DTM (2 м) + бикубическая интерполяция + ~9000 процедурных кратеров
  (частотно-размерное распределение N(>R) ∝ R⁻²) ниже разрешения DTM. Рендер — чанки 250 м с 5 уровнями LOD,
  геометрия строится в Web Worker'ах, «юбки» закрывают щели между уровнями. За пределами участка рельеф
  зеркалируется, поэтому края мира нет.
- **Коллайдер:** heightfield Rapier 128 × 128 м с шагом 0.5 м, подгружается вокруг ровера.
  Крупные камни (> 28 см) — отдельные коллайдеры.
- **Ровер:** `DynamicRayCastVehicleController`, 6 колёс ∅ 82 см, масса 620 кг (LRV + 2 астронавта в скафандрах),
  реальный тензор инерции, все 6 степеней свободы — крен, тангаж, прыжки, перевороты. Мотор-колёса с линейной
  характеристикой момент/скорость, рулятся передняя и задняя оси.
- **Луна:** g = 1.62 м/с², нулевое сопротивление воздуха. Сцепление реголита μ ≈ 0.75, падает на склонах круче 8°.
- **Энергия:** батарея 1.5 кВт·ч (уменьшена для геймплея), расход по механической мощности с КПД 75 %
  и потерям в моторах. Солнечная панель 600 Вт заряжает пропорционально cos угла между её нормалью и Солнцем.
- **Свет:** одно жёсткое низкое Солнце (высота 9°), без рассеянного неба. Тени подсвечены только светом,
  отражённым от реголита, и земным светом. Реголит — модель lunar-Lambert (McEwen) с оппозиционным
  эффектом Хапке: яркое гало вокруг антисолнечной точки, тени ровера и света фар. Металлы и фольга
  ровера дают зеркальные блики. Солнце — диск 0.53° с бликами оптики, гаснущими, когда Солнце закрыто.
  Тени: тени в реальном времени вокруг ровера плюс запечённые тени от рельефа вдали.
- **Небо:** звёзды, Земля в реальном направлении для Хэдли (азимут 188°, высота 64°, 1.9°) с фазой
  от реального направления на Солнце, силуэты гор Хэдли и Хэдли-Дельта.
- **Пыль:** частицы срываются с обода со скоростью v + ω×r и летят по чистым параболам, без облака.
  Частицы, срывающиеся выше ~38°, перехватывают крылья колёс, как на LRV. Мелкая пыль ярко светится
  в контровом свете (прямое рассеяние).
- **Следы** колёс с отпечатками шевронов.
- **Звук:** в вакууме слышно только то, что передаётся через раму, сиденье и скафандр: гул мотор-колёс,
  ШИМ контроллера, шум качения, хруст реголита, удары подвески, сервопривод руля, вентилятор скафандра,
  сигналы предупреждения. При наружной камере механические звуки пропадают — остаются только сигналы по радио.

## Качество и производительность

Пресеты «Низкое / Среднее / Высокое / Ультра» меняют разрешение теней, дальность прорисовки, плотность LOD,
число камней и частиц пыли, pixel ratio. В режиме «Авто» уровень выбирается по устройству
(на телефоне — низкий или средний), а при падении FPS ниже цели (55 на ПК, 30 на телефоне)
игра сначала снижает pixel ratio, затем уровень качества.

## Публикация

`.github/workflows/deploy.yml` собирает проект и публикует его на GitHub Pages при каждом push в `main`.
Base path берётся из имени репозитория (`BASE_PATH=/<repo>/`). PWA (vite-plugin-pwa): манифест,
иконки, полноэкранный режим, альбомная ориентация, precache всех игровых данных для офлайна.

## Источник данных и авторство

- Цифровая модель рельефа **NAC_DTM_APOLLO15** и ортоснимок **M111571816** —
  Lunar Reconnaissance Orbiter Camera (LROC), NASA / GSFC / Arizona State University.
  Архив: [LROC RDR — Apollo 15 DTM](https://data.lroc.im-ldi.com/lroc/view_rdr_product/NAC_DTM_APOLLO15),
  PDS: `LRO-L-LROC-5-RDR-V1.0`.
- Изображение Земли, кратеры, камни и горный горизонт сгенерированы процедурно.
