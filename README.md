# Луноход: борозда Хэдли

Браузерная 3D-игра (PWA): езда на шестиколёсном луноходе от первого лица по **реальному рельефу**
места посадки «Аполлона-15» — борозда Хэдли, участок 4 × 4 км (26.13° с.ш., 3.61° в.д.).
Вокруг участка — реальный рельеф окрестностей на 56 × 56 км (SLDEM2015): гора Хэдли-Дельта, гора Хэдли, Апеннины.
Солнце, Земля и звёзды стоят так, как в начале первого выхода Скотта и Ирвина — 31 июля 1971 года, 13:13 UTC.
Работает на ПК и телефоне, устанавливается как приложение и играет офлайн.
Языки: русский, українська, English, Deutsch, العربية, 中文.

**Играть:** https://vanguar.github.io/moon-rover/

Стек: Vite + TypeScript + Three.js, физика — Rapier (`@dimforge/rapier3d-compat`).

## Запуск

```bash
npm install
npm run dev       # http://localhost:5173/moon-rover/
npm run build     # сборка в dist/
npm run preview   # предпросмотр сборки
```

Нужен Node.js 20+. Игровые данные (`public/data/`, ≈ 10 МБ) уже в репозитории.

### Пересборка данных

1. Скачайте в `raw_data/` (папка в `.gitignore`):
   - DTM: [NAC_DTM_APOLLO15.TIF](https://pds.lroc.im-ldi.com/data/LRO-L-LROC-5-RDR-V1.0/LROLRC_2001/DATA/SDP/NAC_DTM/APOLLO15/NAC_DTM_APOLLO15.TIF) (140 МБ, 2 м/пикс., float32)
   - ортоснимок: [NAC_DTM_APOLLO15_M111571816_50CM.TIF](https://pds.lroc.im-ldi.com/data/LRO-L-LROC-5-RDR-V1.0/LROLRC_2001/EXTRAS/BROWSE/NAC_DTM/APOLLO15/NAC_DTM_APOLLO15_M111571816_50CM.TIF) (560 МБ, 0.5 м/пикс.)
   - звёзды: [bsc5-short.json](https://raw.githubusercontent.com/brettonw/YaleBrightStarCatalog/master/bsc5-short.json) (Yale Bright Star Catalog)
   - созвездия: [constellations.lines.json](https://raw.githubusercontent.com/ofrohn/d3-celestial/master/data/constellations.lines.json) (d3-celestial)
   - дальний рельеф SLDEM2015 — только нужная полоса широт (95 МБ из 1.4 ГБ) Range-запросом:
     ```bash
     curl -r $((1470*92160))-$((2500*92160-1)) -o raw_data/sldem_512_rows_1470_2500.bin        https://pds-geosciences.wustl.edu/lro/lro-l-lola-3-rdr-v1/lrolol_1xxx/data/sldem2015/tiles/float_img/sldem2015_512_00n_30n_000_045_float.img
     ```
2. `pip install rasterio numpy pillow`
3. `python tools/prepare_terrain.py` — heightmap (16-бит PNG), ортоснимки 4096² (весь участок и 0.6 м/пикс. центр),
   маска теней 2 м для реального Солнца, звёзды, `terrain.json`.
4. `python tools/prepare_sky.py` — линии созвездий и галактическая система координат (Млечный Путь).
5. `python tools/prepare_far.py` — дальний рельеф (сетка 112 м, выровнена по DTM), его запечённые тени
   и тени дальних массивов на участке.
6. `python tools/make_icons.py` — иконки PWA.

`tools/ephemeris.py` считает положение Солнца (формула Астрономического альманаха), Земли (ряд для Луны
с либрацией) и ориентацию Луны (модель IAU). При посадке Солнце было на высоте 12° (совпадает с данными
миссии); в игре — начало EVA-1: Солнце — азимут 100°, высота 19°, Земля — азимут 204°, высота 67°.

## Управление

| Действие | Клавиатура | Геймпад | Телефон |
|---|---|---|---|
| Газ | W / ↑ | RT | педаль «ГАЗ» или джойстик вверх |
| Тормоз / назад | S / ↓ | LT | педаль «ТОРМОЗ» или джойстик вниз |
| Руль | A / D, ← / → | левый стик | джойстик или наклон телефона |
| Ручной тормоз (удерживать) | Space | A | — |
| Стояночный тормоз (вкл/выкл) | P | — | кнопка Ⓟ |
| Камера: кабина → снаружи → сверху | C | Y | 📷 |
| Вид сверху | V | — | ⌖ |
| Приближение (снаружи / сверху) | + / −, колесо мыши | — | 🔍 |
| Фары | H | X | кнопка фар |
| Поставить на колёса | R | B / Back | ⟲ |
| Линии созвездий | K | — | кнопка созвездий |
| Приборы поверх экрана в кабине | I | — | касание строки HUD |
| Меню / пауза (продолжить, заново, выйти) | Esc | Start | ⏸ |
| Осмотреться | мышь (перетаскивание) | — | провести по экрану |

На ПК все действия продублированы кнопками справа. На телефоне HUD по умолчанию — одна тонкая строка
(скорость и заряд); касание открывает полную панель. Руление наклоном включается в меню
(на iOS браузер запросит разрешение на датчик ориентации).

## Физика

- **Ровер — сочленённое тело.** Корпус 620 кг (LRV + два астронавта в скафандрах) с реальным тензором инерции.
  Каждое из 6 колёс — отдельное твёрдое тело (∅ 82 см, ширина 23 см, 6 кг) на цепочке сочленений:
  призматическая подвеска с пружиной и демпфером (просадка ≈ 6 см при лунном весе) → поворотный кулак
  с сервоприводом руля → ось колеса. Колесо касается камней своей формой, накатывается на них, тормозится
  о переднюю грань; на камень 20 см ровер подбрасывает, валун 70 см его останавливает.
- **Мотор-колёса:** момент по линейной характеристике «момент — обороты» (39 Н·м при остановке),
  реактивный момент передаётся на корпус. Тормоза — через шарнир колеса. Перегрев моторов снижает момент
  (в вакууме тепло уходит только излучением).
- **Луна:** g = 1.62 м/с², без сопротивления воздуха, сухое трение реголита μ = 0.7 (на склонах — по закону
  Кулона), шаг физики 1/120 с.
- **Энергия:** батарея 1.5 кВт·ч (уменьшена для геймплея), напряжение проседает под нагрузкой,
  солнечная панель 600 Вт заряжает пропорционально косинусу угла к Солнцу.

## Графика

- **Рельеф:** LROC NAC DTM 2 м + ~5500 процедурных кратеров + микрократеры 10–60 см в шейдере;
  у кратеров гладкий профиль (чаша без излома переходит в вал), большинство — сглаженные, как на старой равнине.
  Чанки 250 м с 5 уровнями LOD строятся в Web Worker'ах. Вдали освещение считается по карте нормалей DTM,
  поэтому дальний рельеф резкий. За пределами участка рельеф продолжается моделью SLDEM2015 (LOLA + Kaguya),
  до горизонта — настоящие массивы с кривизной Луны (поверхность уходит вниз на d²/2R).
- **Камни:** булыжники вокруг ровера, глыбы до 6 м и выходы слоистого базальта на бровке и стенках
  борозды (по крутизне склона). Коллайдеры у камней от 10 см рядом с ровером.
- **Свет:** одно низкое Солнце. Реголит — модель lunar-Lambert (McEwen) с оппозиционным эффектом Хапке.
  Тени подсвечены только отражённым светом реголита (~2 %) и землёй. Металлы отражают залитый солнцем грунт
  (карта окружения). Тени: в реальном времени около ровера, запечённые 2 м вдали. Блики оптики от Солнца.
- **Небо:** 9096 звёзд Йельского каталога на реальных местах (яркость 10^(−0.4·m), цвет по температуре,
  без мерцания), Млечный Путь по реальной галактической плоскости, линии созвездий, Земля в реальном
  направлении с правильной фазой. Адаптация глаза: на фоне освещённого грунта видны только яркие звёзды.
- **Метеоры:** на Луне нет атмосферы, поэтому «падающих звёзд» нет. Вместо них изредка видны настоящие
  вспышки ударов метеороидов о грунт — только в тени, где темно.
- **Пыль:** частицы срываются с обода со скоростью v + ω×r и летят по чистым параболам без облака; крылья
  колёс перехватывают частицы, сорвавшиеся выше ~38°. Пыль рисуется штрихами (выдержка кадра), получает
  тени и рассеивает свет вперёд (фазовая функция Хеньи — Гринстейна).
- **Ровер:** проволочные шины с титановыми шевронами (сплющиваются под нагрузкой, смазываются на скорости),
  антенна-зонт из золотой сетки, телекамера GCTA, пульт управления LRV с работающими приборами
  (крен/тангаж, курс, пеленг/дистанция/расстояние до LM, скорость, ампер-часы, вольты, температуры),
  второй астронавт.

## Звук

В вакууме нет звука, поэтому слышно только то, что передаётся через раму, сиденье и скафандр. Звук синтезируется
в AudioWorklet по состоянию физики: удары 18 шевронов каждого колеса, хруст реголита, стуки при наезде на камни
(по реальным силам контакта), коллекторные моторы с передачей 80:1, удары подвески, сервопривод руля — всё через
резонансные моды рамы и фильтр «скафандр + шлем». Плюс вентилятор ранца жизнеобеспечения и дыхание астронавта,
которое учащается при опасном крене и ударах. При наружной камере механические звуки пропадают.

## Качество и производительность

Пресеты «Низкое / Среднее / Высокое / Ультра» меняют разрешение и дальность теней, дальность прорисовки,
LOD, микрократеры, число камней и частиц, pixel ratio; блум — только «Ультра». «Авто» выбирает уровень
по устройству (встроенные GPU и телефоны — ниже) и снижает качество, если FPS долго ниже цели.

## Публикация

`.github/workflows/deploy.yml` собирает проект и публикует его на GitHub Pages при каждом push в `main`.
PWA (vite-plugin-pwa): манифест, иконки, полноэкранный режим, альбомная ориентация, офлайн-кэш данных.

## Источники данных и авторство

- Дальний рельеф: **SLDEM2015** (Barker et al., 2016), LOLA + SELENE TC, NASA/GSFC, PDS Geosciences Node.
- Цифровая модель рельефа **NAC_DTM_APOLLO15** и ортоснимок **M111571816** — Lunar Reconnaissance Orbiter Camera
  (LROC), NASA / GSFC / Arizona State University.
  [LROC RDR — Apollo 15 DTM](https://data.lroc.im-ldi.com/lroc/view_rdr_product/NAC_DTM_APOLLO15), PDS `LRO-L-LROC-5-RDR-V1.0`.
- Звёзды: Yale Bright Star Catalog, 5th ed. (Hoffleit & Warren), JSON — brettonw/YaleBrightStarCatalog.
- Линии созвездий: d3-celestial (Olaf Frohn), BSD-3.
- Земля, кратеры, камни и горный горизонт сгенерированы процедурно.
