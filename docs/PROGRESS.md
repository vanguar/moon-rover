# Прогресс по PROMPT.md

Обновлено: 23.11.2026. Проект уже существовал (Луна и Марс, 7 роверов). `PROMPT.md`
выполняется как доработка, а не написание с нуля.

## Сделано

- **Плавность.** Интерполяция позы ровера между шагами физики, постепенная перестройка
  коллайдера, геоморфинг LOD рельефа, стабилизация камеры в кабине, `npm run probe`.
- **Данные.** Участок 8 × 8 км: DTM 2 м + SLDEM2015 по краям, объекты миссии по реальным
  координатам, высоты Uint16 (экономия памяти), версии данных в URL (кэш не смешивает
  релизы), загрузка в 2 раза быстрее.
- **Освещение.** Эфемерида на TypeScript, ускорение времени, тени рельефа на GPU с
  полутенью (включая тени дальних гор), фотометрия, калиброванная по снимкам Hasselblad,
  реальный Млечный Путь (Gaia), Земля с фазой, звёзды по адаптации глаза.
- **Грунт.** Обломки с тенями, тени в кратерках, зернистость, фактура камней,
  колея как у шины LRV.
- **Модели.** Лунный модуль, Perseverance и Ingenuity от NASA. Износ, пыль и вмятины
  на всех процедурных роверах. Шевроны LRV по реальным размерам.
- **Марс.** Вертолёт Ingenuity: автопилот (T) и ручное управление, физика, звук 84 Гц,
  пыль от винтов. Исправлен рельеф (ложные нормали, полосы).
- **Контроль.** `npm run shots`: сравнения в `docs/comparisons/iter0..3`, итоги в
  `docs/REALISM.md`.

- **Миссии.** Брифинг при старте (клавиша M), задание и расстояние на экране, стрелка-навигатор
  на грунте, цель на мини-карте. Луна: станции «Аполлона-15». Марс: Perseverance к дельте,
  программа полётов Ingenuity.
- **Находки.** ALSEP и LRV на местах стоянки, фото (F) с карточкой архивного снимка NASA, журнал,
  реплики ЦУПа с задержкой 2,6 с.
- **Детальные снимки.** Тайлы в полном разрешении подгружаются вокруг ровера: HiRISE 25 см и
  уклоны из DTM 1 м на Марсе (метровый рельеф с собственными тенями), NAC 50 см по всей полосе
  на Луне. Освещение со снимков HiRISE убрано.
- **Марс сверен с панорамой Perseverance (сол 4):** гравий вокруг ровера, серые камни с пылью,
  песок и пыль различаются оттенком.
