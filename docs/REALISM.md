# Реализм: параметры, источники, контроль

Каждое число в игре должно иметь источник. Где источника нет, значение помечено как
**оценка**. Сравнения со снимками NASA лежат в `docs/comparisons/`, их можно повторить
командой `npm run shots` (см. раздел 9).

## 9. Контроль реализма: итерации

Скрипт `npm run shots` (Playwright + Chrome с GPU) ставит камеру в точку и направление
эталонного кадра, задаёт время съёмки (Солнце по эфемериде) и сохраняет пары
«NASA | игра» в `docs/comparisons/iterN/`. Ракурсы описаны в `docs/shots.json`.
Привязка ракурсов приблизительная: точное место съёмки известно для части кадров, его
уточнение в `docs/PROGRESS.md`.

Эталоны (NASA, общественное достояние, ALSJ): AS15-88-11866, AS15-85-11451,
AS15-82-11121, AS15-82-11147, AS15-86-11654.

### Итерация 0: исходное состояние

- Хэдли-Дельта не видна: камера смотрела на юго-восток вместо юга (ошибка ракурса).
- Грунт в 1,5–2 раза темнее и бежевый (R/B = 1,13 против 1,0 на фото).
- Нет мелочи на переднем плане: мыльная поверхность без обломков и кратерков.

### Итерация 1

- Добавлены обломки с жёсткими тенями по Солнцу, тени внутри кратерков, зернистость.
- Ошибка: тени камешков в 10 раз длиннее нормы. Причина: `smoothstep` с равными
  границами (неопределённое поведение в GLSL), направление и котангенс Солнца теперь
  считаются на CPU.

### Итерация 2

- Время съёмки для каждого кадра (движущееся Солнце). Средняя яркость почти не изменилась:
  причиной было альбедо, а не освещение.
- Найдено расхождение альбедо ближнего грунта (≈ 0,05) и дальних гор (≈ 0,30).

### Итерация 3: калибровка

| Кадр | Средняя яркость грунта, NASA | Игра |
|---|---|---|
| lm_south (AS15-88-11866) | 114 | 125 → после правок 107 |
| ground (AS15-86-11654) | 130 | 143 → после правок 126 |

Цвет нейтральный. Расхождения меньше 10 %. Остаётся меньшая локальная контрастность грунта
(СКО 18–28 против 28–47 на фото): на снимках больше следов ног и мелких ямок.

### Найденные и исправленные дефекты (по ходу)

- Блочные тени на склонах гор: марш луча по высотам без интерполяции (ступеньки 112 м)
  → билинейная интерполяция и запас по уклону.
- Квадраты на грунте: аддитивный value-noise на осевой решётке перекрывал тёмное альбедо
  → относительные вариации и поворот октав.
- Квадрат у ровера: край карты теней реального времени → рельеф затеняется только
  физической маской.
- Ступенчатые «изолинии» на пологих склонах: 8-битные уклоны → корневое кодирование.

## 10. Производительность

`npm run probe` едет 10–12 с и считает время кадров. Ноутбук с Intel Iris Xe, качество
«авто» (среднее): 55–65 FPS, 0 кадров дольше 50 мс. Загрузка на канале 50 Мбит/с:
8,4 с до готовности (было 17 с).
